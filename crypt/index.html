Suivi opérationnel

Les sessions des appareils sont observées à chaque appel API portant les en-têtes CRYPT. Les identifiants de session sont temporaires côté client : le serveur ne prétend pas reconnaître physiquement un appareil après effacement de la session ou rechargement.
Les adresses IP et les agents navigateur sont des signaux techniques, pas une preuve d'identité physique. Plusieurs appareils peuvent partager une même adresse IP.
